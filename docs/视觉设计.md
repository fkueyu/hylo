# Hylo 视觉设计：Structure Mapping Workbench

> 最后更新：2026-08-25

Hylo 的界面不再以“模仿 Xcode”为目标，而是围绕自己的核心能力建立视觉身份：同一个 HTML 元素在文档结构、源码和预览之间存在可见映射。

## 一、设计主张

Hylo 是面向 AI 内容创作者的 HTML 审阅与精调工作台。界面需要同时做到：

- 让预览成为最大的内容画布。
- 让不熟悉代码的用户通过文档结构理解长文档。
- 让源码与预览的双向定位成为可感知的产品特征，而不是隐藏的技术实现。
- 保持桌面工具的紧凑与稳定，不引入网页产品式的大标题、卡片或装饰性数据。

## 二、界面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ Hylo / 文件      [粘贴 HTML] [结构] [布局] [导出] [主题]    │
├────────────┬──────────────────────┬──────────────────────────┤
│ 文档结构   │ HTML 源码 / 当前节点 │ 预览 / 当前节点          │
│ html       │                      │                          │
│ └─ body    │ Monaco Editor        │ HTML 文档画布            │
│    └─ main │                      │                          │
└────────────┴──────────────────────┴──────────────────────────┘
```

- 默认源码/预览比例为 40/60。
- 文档结构位于源码工作区内部，可随时关闭。
- 窄窗口中结构面板变为覆盖层，避免将源码压缩至不可用宽度。
- 面板头共享元素 breadcrumb，点击任意祖先可重新定位。

## 三、颜色与材质

### 暗色工作台

| Token | 色值 | 用途 |
|---|---:|---|
| Graphite 950 | `#15161A` | 顶层窗口背景 |
| Graphite 900 | `#1B1D22` | 源码与结构面板 |
| Graphite 800 | `#202228` | 面板头 |
| Paper | `#F7F8FA` | 预览画布外层 |
| Mapping Violet | `#756FF2` | 主动作与当前选择 |
| Structure Cyan | `#22C7B8` | 结构提示与映射信号 |
| Text Secondary | `#A8ADB8` | 次要界面文字 |

### 浅色工作台

浅色模式使用 `#ECEEF2` / `#F7F8FA` 建立层级，映射紫调整为 `#625BEA`，结构青调整为 `#129F93`。两种主题保持相同的信息层级，不将浅色模式简单处理为颜色反转。

紫色和青色不组成大面积渐变。紫色只表达“动作/选择”，青色只表达“结构/联动”，避免常见的泛 AI 渐变装饰。

## 四、标志性元素：映射轨道

源码与预览之间的分隔线同时是 Hylo 的“映射轨道”。选中节点时，轨道中央出现一次短促青色信号，提示两侧正在指向同一元素。它不持续闪烁，不承担状态文字，也不干扰拖拽调整宽度。

## 五、排版

- UI：系统界面字体（SF Pro / Segoe UI 回退），保证离线与原生观感。
- 代码与结构标签：Monaco 等宽字体栈。
- 面板标签：10px、半粗体，大写和字距只用于稳定栏目名。
- breadcrumb 与结构细节：9–10px 等宽字体，当前节点使用结构青。

## 六、交互状态

- “粘贴 HTML”是唯一高强调工具栏按钮。
- 文档结构开关在开启时使用青色弱背景，不与主动作竞争。
- 结构树当前节点使用紫色左侧标记，id/class 细节使用青色。
- 预览与源码当前元素均使用同一选择状态。
- 所有按钮提供 `:focus-visible`；动效遵循 `prefers-reduced-motion`。

## 七、功能对应

- 剪贴板载入会自动清理 AI 对话常见的 Markdown HTML 代码围栏。
- 普通文本或空剪贴板不会覆盖当前文档。
- 新建及剪贴板载入的未命名文档会被标记为未保存，继续使用现有防丢失流程。
- 文档结构忽略文本、注释和无源码隐式包装节点，但保留其可编辑后代。
