# Hylo 下一步计划

> 更新时间：2026-11-23 · 对应版本：桌面端 0.1.21 / VS Code 扩展 0.1.17
> 定位不变：**对 AI 生成的 HTML 做快捷微调**，不内置 AI，AI 交给外部工具/终端。

---

## 一、本轮交付清单（0.1.21）

### 数据安全
- 原子保存（临时文件 + fsync + rename），未保存修改拦截关闭/切换；
- 自动保存草稿 + 崩溃恢复（2.5s 防抖、异常退出后启动询问恢复，正常保存/丢弃/退出清理）；
- 外部文件变更监听（2s stat 轮询；干净自动重载、脏则询问、删除提示另存）。

### 微调能力
- 预览内双击就地改文字（转义后写回源码，保留 Monaco 撤销栈）；
- 元素属性快速编辑（start-tag 重写，引号/自闭合安全处理）；
- 粘贴 HTML 三选一（替换 / 光标插入 / 新文档）；
- 离线文档审阅（缺 alt、远程资源、空链接、重复 id、标题跳级、内联样式、被阻止脚本，一键定位）；
- 预览诊断徽标（安全预览拦截的脚本/远程资源/交互嵌入计数，点击切交互预览）。

### 性能与稳定性
- Monaco 语言服务裁剪（移除 ts/json worker，节省约 7MB）；
- 预览增量 patch（按节点 id 复用 DOM，不再每次全量重建）；
- 节点 ID 稳定化（显式 id 锚点 + 同标签序号；重复 id 去重）；
- 大纲虚拟化（3000 行仅渲染约 31 行 DOM）；
- 交互预览脚本按哈希复用（打普通文字不再重跑整页 JS / 重拉 CDN）。

### 工程与文档
- CSP / fs scope 收紧，安全预览与交互预览隔离；
- ESLint 9 flat config、CI 质量门禁（tsc/eslint/test/rustfmt/clippy/cargo test）；
- 共享核心单一来源 + `npm run sync:core-vscode` 与漂移检测测试；
- 桌面端 77 个前端测试 + 5 个 Rust 测试；VS Code 扩展 40 个测试；
- README / PRD / 功能特性 / 架构设计 / 开发指南 / CHANGELOG 全量同步；
- VS Code 扩展升级 0.1.17（同步新节点 ID 方案）并重新打包 VSIX（未发布）。

## 三、下一步计划

### P0 · 发布与回归保障（1–2 天）

| # | 事项 | 说明 | 验收标准 |
|---|------|------|----------|
| 1 | 桌面端 0.1.21 发布安装 | 完成上节安装 + 冒烟清单 | `/Applications` 版本为 0.1.21，打开方式生效，冒烟全过 |
| 2 | VS Code 扩展 0.1.17 发布 | 本机安装冒烟后发布 Marketplace/OpenVSX | 市场可安装，预览与结构树正常 |
| 3 | 无头验证脚本入库 | 把本轮用到的 WKWebView DOM harness 沉淀为 `scripts/verify-preview.mjs + .swift`（macOS 本地脚本，CI 跳过），覆盖：增量 patch 节点复用、脚本复用、稳定 ID | 本地一条命令输出 PASS/FAIL，改预览运行时能提前发现回归 |

### P1 · 微调体验闭环（3–5 天）

| # | 事项 | 说明 | 验收标准 |
|---|------|------|----------|
| 4 | 审阅一键修复（低风险项） | 先做「补空 `alt`」「空链接改为 `href="#"` 或删除」；Monaco 编辑 + 撤销友好，操作前预览影响 | 审阅弹窗出现「修复」按钮，一键写入源码且可撤销 |
| 5 | 内联样式外提 | 把选中元素的 `style` 转成 class 写入 `<style>`（可选保留/覆盖），展示 diff | 选中元素即可一键外提，样式不丢失 |
| 6 | 诊断详情与记忆 | 徽标可展开列出被拦截资源前 N 条；交互模式选择按文档记住（session 级） | 白屏时能明确看到是哪个资源被拦，重复打开同一文档不再反复确认 |
| 7 | 定位动效与联动 | 审阅/大纲/源码/预览四处选中状态统一高亮 + 平滑滚动 | 任意入口定位时另外三处同步可见 |

### P2 · 技术债与能力扩展（1–2 周）

| # | 事项 | 说明 | 验收标准 |
|---|------|------|----------|
| 8 | AST 增量解析 | Worker 只重解析变化区块 + nodeMap 局部更新，替代整篇重解析 | 1MB/8000 节点文档连续输入时解析耗时与内存明显下降（可用 bench 对比） |
| 9 | 交互脚本依赖细化 | 变化点之后整体重放 → 按脚本依赖/模块粒度重放，进一步减少重跑 | 修改一个内联脚本不触发其它无关脚本，顺序正确 |
| 10 | UI 测试基础设施 | 引入 jsdom 或 Playwright + tauri-driver（macOS 本地），覆盖弹窗/工具条/快捷键 | 关键交互有自动化用例，CI 跑可跑部分 |
| 11 | 首屏体积继续优化 | `html-to-docx` 改为导出时动态 import；Monaco 按需加载 | 主 chunk 明显下降，导出功能不受影响 |
| 12 | 多标签/最近文件增强 | 产品决策后做（当前单文档 + 历史列表是否够用） | — |

### 明确不做
- 内置 LLM 生成 / 行内 AI 改写 / 云同步账号体系（保持「外部 AI 生成 → Hylo 微调」边界）。
- 为单一厂商/平台定制的专用接入（与产品定位无关）。

## 四、建议的迭代节奏

1. **本周**：P0 三项（发布 + 冒烟 + 无头验证入库），把 0.1.21/0.1.17 交付到用户手里；

3. **之后**：P2 按收益排序，优先 8（增量解析）与 10（测试基础设施）。
